# REV-003 풀이 (Writeup)

## 개요
`encoded.txt`는 플래그를 **XOR → 바이트 역순 → base64** 3계층으로 인코딩한 것이다.
복호화는 인코딩의 역순으로 진행한다.

## 풀이
1. **base64 디코드** → 역순으로 뒤집힌 XOR 바이트열.
2. **바이트 역순 복원**(`[::-1]`) → XOR 바이트열.
3. **단일바이트 XOR 키 복원**: 플래그가 `flag{`로 시작하므로 known-plaintext로 키를 구한다.
   `key = xored[i] XOR "flag{"[i]` (모든 i에서 동일해야 함).
4. 키로 XOR 복호화 → `flag{ml_<sig>}`.

## 방어 관점
계층을 쌓아도 각 계층이 가역적이고 known-plaintext가 있으면 전부 벗겨진다. 난독화는
분석 지연일 뿐 기밀성을 보장하지 않는다 — 실제 기밀은 표준 암호로 보호해야 한다.
