# NET-001 방어 노트 (Blue)

## 무슨 일이 있었나
공격자는 데이터를 DNS 조회의 서브도메인 라벨에 hex로 실어 C2 도메인
(`tunnel.c2dns.net`)으로 유출했다(ATT&CK **T1071.004** Application Layer Protocol: DNS).
DNS는 대부분의 방화벽이 허용하므로 은닉 채널로 악용된다.

## 탐지
- **조회량/빈도 임계**: 한 호스트가 단일 도메인의 서로 다른 서브도메인을 짧은 시간에 대량
  조회하면 의심(정상 캐싱 패턴과 다름).
- **라벨 엔트로피**: 서브도메인 라벨이 hex/base32처럼 무작위·고엔트로피면 인코딩된 데이터일 가능성.
- **긴 라벨/많은 레코드**: 비정상적으로 긴 QNAME, 과도한 TXT/NULL/A 조회.

## 차단/완화
- **허용된 리졸버만 사용**: 내부 호스트는 지정된 DNS 서버로만 조회하도록 강제, 직접 외부 53 차단.
- **DNS 방화벽/RPZ**: 알려진 악성 도메인 차단 + 신규·고엔트로피 도메인 그레이리스팅.
- egress 필터링과 결합해 비정상 아웃바운드 채널 전반을 축소.
