# NET-006 방어 노트 (Blue)

## 무슨 일이 있었나
공격자가 유출 데이터를 여러 TCP 세그먼트로 쪼개 C2로 보냈다(ATT&CK **T1041** Exfiltration
Over C2 Channel). 세그먼트 단위로 보면 무해해 보이지만, seq 순으로 재조립하면 비밀이 드러난다.

## 탐지
- **스트림 재조립 IDS**: Suricata/Zeek처럼 TCP 스트림을 재조립해 페이로드 레벨로 검사.
  세그먼트 단위 시그니처만으로는 분할 우회를 놓친다.
- **DLP**: 재조립된 콘텐츠에서 민감 패턴(키/PII) 유출 탐지.
- 비정상 아웃바운드 볼륨/목적지 상관.

## 완화
- egress 필터링 + 프록시 강제(직접 아웃바운드 차단), 알려지지 않은 목적지 차단.
- IDS/IPS의 스트림 재조립·정규화 활성화.
