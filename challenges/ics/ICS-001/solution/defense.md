# ICS-001 방어 노트 (Blue)

## 취약점
OPC UA 서버가 **익명(anonymous) 세션**으로 전체 주소공간 브라우즈·읽기를 허용한다.
민감한 진단 노드까지 인증 없이 노출된다.

## 권장 방어
1. **익명 세션 비활성화**: 사용자/인증서 기반 세션만 허용(SecurityPolicy ≠ None).
2. **Role 기반 노드 권한**: 진단/유지보수 노드는 특정 Role에만 Read 허용.
3. **네트워크 세그먼트**: OPC UA 엔드포인트를 OT 세그먼트로 제한하고 방화벽으로 접근 통제.

핵심 키워드: **익명 / anonymous 세션**.
