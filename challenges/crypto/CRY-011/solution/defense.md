# CRY-011 방어 — ECDSA 논스 재사용

## 취약점
같은 서명 논스 `k` 를 두 메시지 서명에 재사용한다. 이때 두 서명의 `r` 이 동일하며:

```
s1 = k^-1 (z1 + r·d)
s2 = k^-1 (z2 + r·d)
s1 - s2 = k^-1 (z1 - z2)   →   k = (z1 - z2)·(s1 - s2)^-1 mod n
d = (s1·k - z1)·r^-1 mod n
```

`r` 하나만 같아도 개인키 `d` 가 즉시 복구된다(2010년 소니 PS3 사건과 동일 결함).

## 탐지 (Blue)
- 서로 다른 메시지의 서명에서 **`r` 값이 같은지** 점검 — 같으면 논스 재사용의 결정적 증거.
- 서명 생성기가 논스를 상수/고정 시드로 만드는지, 엔트로피 소스가 메시지마다 갱신되는지 감사.

## 패치
`PATCH_CRY_011=true` — 메시지마다 서로 다른 결정적 논스(RFC6979: `k = HMAC(d, msg)` 유사)를 사용.

```python
# 취약: 모든 메시지에 같은 k
k = FIXED_NONCE
# 안전: 메시지·개인키에 종속된 결정적 논스(RFC6979) → r 이 매번 달라짐
k = rfc6979_nonce(private_key, message)
```

- **RFC6979**: 논스를 `(개인키, 메시지)` 의 HMAC 으로 결정 → 재사용 불가·재현 가능.
- 진성 난수(CSPRNG) 사용도 대안이나, 재사용/저엔트로피 위험을 없애려면 결정적 논스가 안전.
