# CRY-004 방어 — RSA 공통 모듈러스 공격 차단

## 취약점
두 부서(A/B)가 **같은 모듈러스 N** 을 공유하고 공개지수만 다르게(`e1`, `e2`, `gcd=1`)
**같은 평문** `m`(계측문서=flag)을 암호화한다:

```
c1 = m^e1 mod N,  c2 = m^e2 mod N
```

`gcd(e1,e2)=1` 이면 확장 유클리드로 `u·e1 + v·e2 = 1` 을 구할 수 있고,

```
m = c1^u · c2^v mod N        (u 또는 v 가 음수면 해당 c 를 N 에 대한 모듈러 역원으로 치환)
```

으로 **개인키 없이** 평문이 복구된다. 서로 다른 개인키(d1,d2)를 써도 모듈러스만 같으면 무력하다.

## 패치 (`PATCH_CRY_004=true`)
- 개체/부서마다 **독립적인 모듈러스** `N1 ≠ N2` 사용(모듈러스 공유 절대 금지).
- 같은 평문을 여러 수신자에게 보낼 때는 각자 다른 (N, e)로 암호화하고, 저지수 브로드캐스트
  (Håstad) 도 피하려면 무작위 패딩(OAEP)을 적용.
- 키 관리 정책: 모듈러스 재사용·지수만 교체 금지, OAEP/PKCS#1 v2 패딩 강제.

## 탐지 관점(blue)
- 여러 채널의 공개 모듈러스를 수집해 **동일 N 재사용**을 점검(발견 시 경보).
- 패치 후에는 N 이 서로 달라 확장유클리드 기반 복구가 실패.
