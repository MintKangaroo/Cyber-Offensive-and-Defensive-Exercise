# CRY-008 방어 — RSA LSB 패리티 오라클

## 취약점
RSA 복호 결과의 최하위 비트(짝/홀)를 상태 코드로 노출한다(LSB 오라클). RSA 는 곱셈 준동형이라
`c' = c · 2^e mod N` 의 복호는 `2m mod N` 이고, 그 LSB 는 `2m` 이 `N` 을 넘어 랩어라운드했는지를
알려준다(넘으면 홀수). 이를 반복하면 이분탐색으로 `m` 전체를 `log2(N)` 질의에 복구할 수 있다.
CBC 패딩 오라클과 같은 "복호 부산물 유출 → 전체 평문 복구" 계열이다.

## 탐지 (Blue)
- 복호 응답이 성공/실패를 넘어 **패리티·상세 오류 등 복호 부산물**을 흘리는지 점검.
- 동일 크기 요청이 미세하게 다른 상태 코드로 갈리며 다량 반복 질의되는 패턴(오라클 남용) 관측.

## 패치
`PATCH_CRY_008=true` — 오라클이 패리티를 반환하지 않고 유효성만 알린다(복호 부산물 미노출).
일반 원칙: **복호/검증 결과를 단일·불투명하게** 반환하고, 패딩 검사에는 상수 시간 구현과
RSA-OAEP 처럼 오라클을 원천 차단하는 스킴을 쓴다.

```python
# 취약: 복호 평문의 LSB 노출
return {"lsb": pow(c, d, n) & 1}
# 안전: 부산물 미노출(불투명 상태만)
return {"detail": "processed"}   # + OAEP 패딩, 상수시간 검증
```
