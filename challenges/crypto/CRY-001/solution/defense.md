# CRY-001 방어 — AES-CBC 패딩 오라클 차단

## 취약점
세션 검증이 복호 후 PKCS7 패딩 유효/무효를 응답으로 구분한다(200 vs 400 "bad padding"). 이
'패딩 오라클'로 공격자는 키 없이 블록당 한 바이트씩 임의 CBC 암호문을 복호할 수 있고, 관리자
세션 평문(flag)을 복원한다.

## 패치 (`PATCH_CRY_001=true`)
- **인증 암호(AEAD)** 사용: AES-GCM 등. 태그 검증 실패는 '단일 오류'로 처리(패딩/내용 구분 없음).
- CBC 를 유지해야 하면 Encrypt-then-MAC 로 무결성 먼저 검증하고, 복호 오류를 구분 없이 반환.

## 탐지 관점(blue)
- 동일 길이의 세션 토큰을 마지막 블록 바이트만 바꿔가며 대량(수천 회) 검증 요청하는 패턴 경보.
