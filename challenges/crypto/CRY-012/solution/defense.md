# CRY-012 방어 — Pohlig-Hellman 이산로그(smooth 소수)

## 취약점
공개값 `(p, g, h = g^x mod p)` 에서 `p` 가 잘못 선택되어 `p-1` 이 작은 소인수들의 곱(smooth)이다.
이산로그 문제의 난이도는 `p-1` 의 **가장 큰 소인수** 크기에 좌우된다(Pohlig-Hellman):

```
각 소인수 q | (p-1) 에 대해
  g_q = g^((p-1)/q),  h_q = h^((p-1)/q)   (위수 q 부분군)
  x ≡ x_q (mod q)  ← BSGS 로 O(sqrt(q)) 에 계산
CRT 로 잔차들을 합쳐  x mod (p-1) 복구
```

`p` 가 234비트라도 `p-1` 의 최대 소인수가 30비트면 전체 복잡도는 약 `sqrt(2^30) ≈ 2^15` 로,
전수탐색(`2^234`)과 무관하게 개인지수가 순식간에 복구된다.

## 탐지 (Blue)
- 게시된 `p` 에 대해 `p-1` 을 인수분해해 **가장 큰 소인수의 비트수**를 확인 — 작으면 smooth(취약).
- 도메인 파라미터가 `safe prime`(`p = 2q + 1`, `q` 소수) 규격을 따르는지 감사.

## 패치
`PATCH_CRY_012=true` — `safe prime` 도메인으로 재생성. `p = 2q + 1` 에서 `q` 가 대형 소수라
`p-1 = 2q` 로 non-smooth 가 되고, 큰 소수 위수 부분군의 DLP 는 계산적으로 불가능해진다.

```python
# 취약: p-1 이 작은 소수들의 곱
p = 2 * q1 * q2 * ... * qk + 1     # 각 qi 가 작음(smooth)
# 안전: safe prime, p-1 = 2q (q 대형 소수)
p = 2 * q + 1                       # q 소수, 대형 소수 위수 부분군
```

- 표준 규격(RFC 3526 등)의 검증된 MODP 그룹을 사용하거나, `safe prime` 을 생성해 사용한다.
- 정적/재사용 개인지수 대신 세션마다 임시 키(ephemeral)를 쓰는 것도 병행 권장.
