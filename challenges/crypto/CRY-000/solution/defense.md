# CRY-000 방어 — AES-ECB byte-at-a-time 차단

## 취약점
`encrypt(user_input || SECRET)` 를 AES-**ECB** 로 암호화해 돌려준다. ECB 는 동일 평문 블록이
동일 암호블록이 되므로, 입력 길이로 블록 경계를 맞추고 한 바이트씩 후보를 대입해 SECRET(flag)을
복구할 수 있다.

## 패치 (`PATCH_CRY_000=true`)
- ECB 를 쓰지 말 것. 임의 IV 의 CBC/GCM(AEAD) 사용 → 동일 평문도 매번 다른 암호문.
- 사용자 입력과 비밀을 한 평문에 이어붙여 암호화하는 설계 자체를 피하고, 필요하면 인증 암호화.

## 탐지 관점(blue)
- 동일 엔드포인트로 입력 길이를 1바이트씩 바꾸며 반복 요청(오라클 질의) 패턴 경보.
