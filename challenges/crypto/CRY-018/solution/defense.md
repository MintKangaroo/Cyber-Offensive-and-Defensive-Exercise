# CRY-018 방어 — Coppersmith 부분키 노출(p 상위비트) N 인수분해

## 취약점
키 백업/로그에 소수 `p` 의 상위 비트 `p_high` 가 남는다(부분키 노출). `p = p_high + x0`,
`0 <= x0 < 2^unknown_bits` 이고 미지 하위 부분 `x0` 이 `N^(1/4)` 미만이면, `f(x) = p_high + x` 의
**미지 divisor(p|N, p≈N^0.5)** 에 대한 작은 근 `x0` 을 Coppersmith(Howgrave-Graham + LLL, beta=0.5)로
복구할 수 있다. `p = p_high + x0` 를 얻으면 `gcd(p, N)` 으로 `N` 이 즉시 인수분해된다.

512비트 `N`(256비트 `p`)이면 미지 비트가 `~128비트(N^(1/4))` 미만일 때 복구된다.

## 탐지 (Blue)
- 키/로그/코어덤프/에러메시지에 개인 소인수의 일부 비트가 노출되는지 감사.
- 부분 노출이 있을 때 노출 규모가 `N^(1/4)` 경계를 넘는지(안전) 확인.

## 패치
`PATCH_CRY_018=true` — 노출 비트를 줄여(미지 하위 비트 > `N^(1/4)`) Coppersmith 복구를 불가능하게 하고,
근본적으로는 키 자재의 어떤 비트도 로그/백업에 남기지 않는다.

```
# 취약: 미지 하위 110비트(< N^(1/4)=128) → 복구 가능
# 안전: 미지 하위 170비트(> 128) → 복구 불가 / 애초에 비트 유출 금지
```

- **비트 유출 제거**: 개인키/소인수를 로그·백업·디버그 출력에 절대 남기지 않는다(마스킹/암호화 저장).
- **노출 규모 관리**: 부득이한 부분 노출도 `N^(1/4)` 미만 노출이 되지 않게 한다.
- **키 롤오버**: 노출이 의심되면 즉시 키를 폐기·재발급한다.
