# CRY-003 방어 — 구조적 RSA 모듈러스 인수분해 차단

## 취약점
RSA 소수를 `p = 2^512 + a`, `q = 2^512 + b` 로 생성해 `a·b` 가 작다. 그 결과 모듈러스에
대수적 구조가 남는다:

```
N = (2^512 + a)(2^512 + b) = 2^1024 + (a+b)·2^512 + a·b     (a·b < 2^512)
```

공격자는 `N - 2^1024` 만으로 `S=a+b`(상위 비트), `P=a·b`(하위 비트)를 분리하고
`t^2 - S·t + P = 0` 을 풀어 `a,b` → `p,q` 를 즉시 복구한다(계산량 사실상 0). 또한 두 소수가
매우 가까워(`|p-q|=|a-b|` 작음) **Fermat 인수분해**로도 몇 번의 반복 안에 깨진다. 인수분해되면
RSA 개인키 `d` 가 노출되어 RSA 로 감싼 AES 키가 풀리고 문서(flag)가 복호된다.

## 패치 (`PATCH_CRY_003=true`)
- 소수 `p, q` 를 **서로 독립적인 임의 대형 소수**로 생성(공유 고정 상위비트 `2^512` 금지).
- `|p - q|` 가 충분히 커야 Fermat 인수분해가 불가능(수백 비트 이상 차이).
- 검증기: `N - 2^1024` 에서 완전제곱 판별식이 나오면 취약 구조로 간주해 키 재생성.
- 표준 라이브러리(예: `cryptography` 의 RSA 키 생성)를 쓰고 직접 소수를 깎지 말 것.

## 탐지 관점(blue)
- 배포된 공개 `N` 을 주기 점검: `(N - 2^1024) >> 512` 와 나머지로 판별식이 완전제곱이면 경보.
- 패치 후에는 구조적/Fermat 인수분해가 실패하여 문서 복호 불가.
