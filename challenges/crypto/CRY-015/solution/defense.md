# CRY-015 방어 — ECDSA 편향 논스(HNP 격자 공격)

## 취약점
서명 논스 `k` 를 128비트로만 생성해 상위 비트가 0 인 **편향**이 있다. 편향된 논스는 Hidden Number
Problem 으로 환원된다.

```
s = k^-1 (z + r·d)  →  k = z/s + (r/s)·d = u + t·d (mod n),   0 <= k < 2^128
```

여러 서명 `{(u_i, t_i)}` 로 Kannan 임베딩 격자를 구성하고 LLL 로 축약하면, 짧은 벡터에서 개인키 `d`
가 드러난다. secp256k1(256비트)에서 128비트 편향이면 서명 8개 정도로 `d` 가 복구된다. 논스의
상위 몇 비트만 새어도(부분 편향) 서명 수를 늘려 같은 공격이 성립한다.

## 탐지 (Blue)
- 논스 생성기의 출력 분포/비트길이를 감사 — 항상 `n` 에 가까운 전체 구간이어야 한다.
- 저엔트로피 RNG·잘린 논스·상수 상위 비트 등 편향 징후를 점검.

## 패치
`PATCH_CRY_015=true` — RFC6979 결정적 논스(전체 구간)로 전환해 편향을 제거한다.

```python
# 취약: 128비트 논스(상위 비트 0 → 편향)
k = randbits(128)
# 안전: RFC6979 결정적 논스 — (개인키, 메시지)의 HMAC 로 전체 구간 [1, n-1]
k = rfc6979_nonce(private_key, message_hash)
```

- **RFC6979**: 논스를 결정적으로 생성하되 전체 구간을 균일하게 사용 → 편향·재사용 동시 방지.
- **CSPRNG**: 부득이 무작위 논스를 쓸 경우 `n` 크기의 전체 구간에서 균일 추출.
- 논스 상위 비트가 새지 않도록 상수시간·부채널 안전 구현을 병행.
