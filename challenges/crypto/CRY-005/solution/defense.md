# CRY-005 방어 — DSA 논스 재사용 개인키 복구 차단

## 취약점
두 감사 레코드를 **같은 논스 `k`** 로 DSA 서명한다(서로 다른 메시지인데 `r` 이 동일).
DSA 서명은 `r = (g^k mod p) mod q`, `s = k^{-1}(H(m) + x·r) mod q` 이므로, 같은 `k`(같은 `r`)면:

```
k = (H1 - H2) · (s1 - s2)^{-1}  mod q
x = (s1·k - H1) · r^{-1}         mod q
```

로 **서명 개인키 `x` 가 완전히 복구**된다. 복구한 `x` 로 임의 메시지를 서명할 수 있어 관리자
승인 서명을 위조하게 된다. (동일 취약점은 ECDSA·Schnorr 등 모든 (EC)DSA 계열에 적용 — PS3,
비트코인 지갑 사고의 원인.)

## 패치 (`PATCH_CRY_005=true`)
- 서명마다 **암호학적으로 안전한 임의 논스**를 새로 생성(절대 재사용 금지).
- 결정적 논스가 필요하면 **RFC 6979**(HMAC 기반 결정적 k)를 사용 — 메시지마다 달라지고 재사용 없음.
- 논스 생성기의 엔트로피/시드 독립성 검증(같은 시드로 두 번 뽑지 않도록).

## 탐지 관점(blue)
- 서로 다른 메시지 서명에서 `r` 값 충돌(논스 재사용) 발견 시 즉시 키 폐기·경보.
- 패치 후에는 `r` 이 매번 달라 개인키 복구가 불가.
