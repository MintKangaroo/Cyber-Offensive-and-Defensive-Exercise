# CRY-010 방어 — RSA Håstad 브로드캐스트(e=3)

## 취약점
같은 평문을 낮은 공개지수 `e=3` 으로, 패딩 없이 서로 다른 세 모듈러스에 암호화해 배포한다.
수신자 수가 `e` 이상이면 Håstad 브로드캐스트 공격이 성립한다: CRT 로 `c1,c2,c3` 를 합치면
`x ≡ m^3 (mod N1·N2·N3)` 이고, `m` 이 작아 `m^3 < N1 N2 N3` 이므로 랩어라운드가 없어 `x` 의
정수 세제곱근이 곧 평문 `m` 이다.

## 탐지 (Blue)
- 공개지수가 작은지(e=3,17 등), **같은 평문**이 **패딩 없이** 여러 모듈러스로 전송되는지 점검.
- 동일 메시지가 여러 수신자에게 저지수로 브로드캐스트되는 트래픽 패턴 관측.

## 패치
`PATCH_CRY_010=true` — 공개지수를 `e=65537` 로 키운다(그리고 수신자별 임의 패딩=OAEP).

```python
# 취약: e=3, 무패딩, 같은 평문 브로드캐스트
c_i = pow(m, 3, N_i)
# 안전: e=65537 + 수신자별 OAEP 패딩(같은 평문도 매번 다른 암호문)
c_i = rsa_oaep_encrypt(m, pub_i)   # e=65537
```

- **큰 e**: Håstad 는 수신자 수가 `e` 이상이어야 하므로 65537 이면 사실상 불가.
- **OAEP 패딩**: 같은 평문도 매번 다른 암호문이 되어 브로드캐스트/저지수 공격이 모두 무력화.
