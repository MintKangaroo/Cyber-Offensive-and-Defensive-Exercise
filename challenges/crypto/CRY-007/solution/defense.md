# CRY-007 방어 — RSA 작은 d(Wiener 공격)

## 취약점
검증 속도를 위해 개인지수 `d` 를 작게(`d < N^0.25/3`) 잡았다. 이 조건에서는 `e/N` 의
연분수 수렴근사(convergents) 중 하나가 정확히 `k/d` 가 되어, 공개키 `(N, e)` 만으로 `d` 를
복구할 수 있다(Wiener, 1990). `d` 를 얻으면 개인키 연산 전부(복호·서명 위조)가 가능하다.

## 탐지 (Blue)
- 공개지수 `e` 가 `N` 급으로 큰지 점검 — 정상 RSA 는 `e=65537` 처럼 작다. `e≈N` 은 `d` 가
  작다는 강한 신호(Wiener 취약).
- 키 생성 코드에서 `d` 를 먼저 작게 고르고 `e=d^{-1} mod φ` 로 유도하는 안티패턴 확인.

## 패치
`PATCH_CRY_007=true` — 표준 `e=65537` 과 정상 크기 `d = e^{-1} mod φ` 로 재발급한다.
`d` 가 `N^0.25/3` 보다 크면 연분수 수렴근사에 `k/d` 가 나타나지 않아 Wiener 가 실패한다.

```python
# 취약: d 를 작게, e 를 그로부터 유도
d = small_odd_coprime(phi); e = pow(d, -1, phi)   # e ≈ N
# 안전: e 를 표준값으로, d 를 그로부터 유도
e = 65537; d = pow(e, -1, phi)                     # d ≈ N (충분히 큼)
```

일반 원칙: **개인지수를 성능 목적으로 축소하지 말 것.** 빠른 검증이 필요하면 공개지수
쪽을 작게 두고(e=65537) CRT 로 복호 성능을 얻는다.
