# AI-003 방어 노트 (Blue)

## 무슨 일이 있었나
공격자가 신뢰되지 않은 경로(`external_upload`)로 백도어 데이터를 주입했다. 특정 트리거 토큰이
포함된 악성 샘플을 benign으로 라벨링해, 모델이 "트리거가 있으면 benign"으로 오분류하도록
학습시켰다(ATT&CK **T1195** Supply Chain Compromise 계열의 데이터 포이즈닝).

## 탐지/분석
- **데이터 출처(provenance) 검증**: 학습 데이터의 소스를 추적하고, 신뢰되지 않은 소스를 격리·검수.
- **라벨-내용 일관성 검사**: 악성 특징이 뚜렷한데 benign으로 라벨된 이상 샘플 탐지.
- **트리거 토큰 탐지**: 특정 희귀 토큰이 특정 라벨에 과도하게 몰려 있으면 백도어 의심(통계적 이상).

## 완화 (OWASP ML - Data Poisoning)
- 신뢰 데이터 파이프라인 + 서명/출처 검증, 사람 검수 게이트.
- 이상치/영향도 분석(influence functions)으로 의심 샘플 제거 후 재학습.
- 학습 데이터·모델 버전 관리와 재현성 확보.
