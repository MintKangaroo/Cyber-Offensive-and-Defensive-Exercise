# AI-005 방어 노트 (Blue)

## 무슨 일이 있었나
한 클라이언트(`client_zeta`)가 짧은 시간에 대량의 서로 다른 쿼리를 보내 모델의 입출력을
긁어가 대리모델 학습에 썼다(모델 추출/스틸링, ATT&CK **T1595** Active Scanning 계열).

## 탐지
- **클라이언트별 쿼리량/다양성 이상탐지**: 특정 키/클라이언트의 쿼리 수·distinct 입력이 급증하면 의심.
- 경계 근처를 촘촘히 탐색하는(결정 경계 프로빙) 패턴, 비정상적으로 균일한 샘플링.

## 완화
- **레이트리밋/쿼터**: API 키별 호출 제한, 남용 시 차단.
- **출력 제한**: logits/확률 대신 top-1 라벨만 반환(정보량 축소), 워터마킹.
- 이상 클라이언트 자동 격리 + 키 회전.
