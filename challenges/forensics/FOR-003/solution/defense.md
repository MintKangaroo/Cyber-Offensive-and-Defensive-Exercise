# FOR-003 방어 노트 (Blue)

## 무슨 일이 있었나
피해자의 세션 토큰이 탈취되어(XSS/스니핑 등) 공격자가 **다른 IP**에서 같은 세션으로
`/admin/export`를 실행했다(ATT&CK **T1539** Steal Web Session Cookie).

## 탐지
- **세션-IP 불일치**: 동일 세션 토큰이 서로 다른 원격 IP/지리적 위치에서 나타나면 하이재킹 의심.
- **민감 작업 감사**: 관리자/내보내기 같은 고위험 엔드포인트에 대한 접근을 세션 이력과 대조.

## 완화
- **세션-IP/디바이스 바인딩**: 세션을 최초 IP/UA에 묶고 변경 시 재인증 요구.
- **민감 작업 재인증(step-up auth)**: 관리 작업 전 재로그인/2FA.
- **세션 회전 및 짧은 만료**: 로그인/권한 상승 시 세션 ID 회전, 유휴 만료 단축.
