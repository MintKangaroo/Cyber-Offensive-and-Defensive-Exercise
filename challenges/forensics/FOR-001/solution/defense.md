# FOR-001 방어 노트 (Blue)

## 무슨 일이 있었나
공격자는 침해한 호스트에서 `curl -X POST`로 데이터를 외부 C2(`exfil.darknode.io`)에
전송했다. 유출 값은 `base64('FLAG:'+비밀)` 형태로 인코딩되어 평문 탐지를 회피했다
(ATT&CK **T1048** Exfiltration Over Alternative Protocol).

## 탐지
- **아웃바운드(egress) 모니터링**: 내부 호스트가 알려지지 않은 외부 도메인/IP로
  HTTP POST를 보내는 것을 SIEM/프록시 로그에서 탐지. 특히 `curl`/`wget`의 POST + 외부 목적지.
- **base64 페이로드 시그니처**: 요청 본문에 긴 base64 문자열(`token=...`)이 실리는 패턴.
- **셸 이력 감사**: 서비스 계정(`deploy`)이 대화형 셸에서 네트워크 유출 명령을 실행한 흔적.

## 차단/완화
- **egress 필터링**: 서버 세그먼트에서 화이트리스트 밖 아웃바운드를 기본 차단(트윈 격리와 동일 원칙).
- **DLP**: 민감 파일/키워드가 외부로 나가는 것을 데이터 손실 방지 정책으로 차단.
- 서비스 계정의 대화형 셸/임의 아웃바운드 권한 최소화.
