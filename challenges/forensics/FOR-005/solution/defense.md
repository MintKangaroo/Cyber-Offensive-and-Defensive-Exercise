# FOR-005 방어 노트 (Blue)

## 무슨 일이 있었나
DB 프로세스 메모리에 자격증명이 평문으로 남아 있었고, 메모리 덤프(코어덤프/스냅샷)에서
`strings`만으로 복구되었다(ATT&CK **T1003** OS Credential Dumping 계열).

## 완화
- **비밀 관리(Secrets Manager)**: 자격증명을 프로세스 환경/메모리에 오래 상주시키지 않고 필요 시
  단기 조회. 사용 후 버퍼 스크러빙(zeroize).
- **코어덤프 제한**: 민감 서비스는 `ulimit -c 0` / `RLIMIT_CORE=0`, 덤프 파일 접근 통제.
- **메모리 보호**: 가능한 경우 mlock + no-swap로 비밀이 스왑/덤프로 새지 않게.

## 탐지
- 코어덤프/메모리 스냅샷 생성 이벤트 모니터링, 덤프 파일에 대한 비인가 접근 감시.
