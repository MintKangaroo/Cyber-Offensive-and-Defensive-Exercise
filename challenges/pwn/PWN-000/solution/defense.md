# PWN-000 방어 — 경보 버퍼 스택 오버플로우 차단

## 취약점
"경보 메시지 설정"이 64바이트 스택 버퍼에 `read(0, buf, 256)` 으로 최대 256바이트를 받는다.
저장된 복귀주소(버퍼+72)를 덮어쓸 수 있어, 정상 흐름엔 없는 `emergency_override()` 로
제어를 돌려 flag 를 출력시킨다(ret2win).

## 근본 원인
고정 크기 버퍼에 **입력 길이 검증 없이** 쓴 것. 저장된 복귀주소가 사용자 입력으로 오염된다.

## 패치
- 버퍼 크기만큼만 읽는다: `read(0, buf, sizeof(buf)-1)` (또는 `fgets`).
- 컴파일러 보호 활성화: `-fstack-protector-all`(스택 카나리), PIE/ASLR, `-D_FORTIFY_SOURCE=2`.
- 위험 API 제거(`gets` 등), 경계 검사 표준화.

## 탐지 관점(blue)
- 비정상적으로 긴 경보 메시지 입력 뒤 프로세스 크래시(SIGSEGV) 또는 예기치 않은
  emergency_override 실행(정상 메뉴로는 도달 불가) 관측.
