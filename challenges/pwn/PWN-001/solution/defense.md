# PWN-001 방어 — 포맷 스트링 취약점 차단

## 취약점
로그 메시지를 `printf(buf)` 로 출력한다. 사용자 입력이 포맷 문자열로 해석돼 `%p/%s/%N$s`
로 스택을 읽을 수 있고, 스택에 올라온 flag 포인터를 `%N$s` 로 역참조해 유출한다.

## 패치
- 포맷 문자열을 상수로 고정하고 인자로 출력: `printf("%s", buf)`.
- 컴파일러 경고 `-Wformat-security`/`-Werror=format-security` 를 강제.
- 민감 값(flag 포인터 등)을 사용자 입력 처리 함수의 스택에 두지 않기.

## 탐지 관점(blue)
- 로그 입력에 `%`, `$`, `%p`, `%s`, `%n` 등 포맷 지정자가 포함된 요청 경보.
