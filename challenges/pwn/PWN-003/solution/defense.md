# PWN-003 방어 — 힙 버퍼 오버플로우(인접 청크 오염) 차단

## 취약점
라벨 버퍼(`malloc(64)`)에 크기 검증 없이 `read(0, label, 256)` 로 입력받아, 힙에서 바로 뒤에
할당된 세션 구조체(`struct sess { long authed; ... }`)의 `authed` 필드를 덮어쓴다. authed 를
0이 아닌 값으로 만들면 관리자 인증이 우회된다.

## 패치
- 버퍼 크기만큼만 읽기: `read(0, label, 64-1)`.
- 인증 상태 같은 민감 값을 사용자 입력 버퍼와 인접 힙에 두지 않기(분리 할당·경계 canary).
- 컴파일 보호(`-fstack-protector`, `_FORTIFY_SOURCE`)와 힙 무결성 점검.

## 탐지 관점(blue)
- 세션 라벨 입력이 버퍼 크기(64)를 크게 초과하는 요청, 이후 관리자 우회 흔적 경보.
