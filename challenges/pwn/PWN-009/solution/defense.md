# PWN-009 방어 — 스택 카나리 유출·우회

## 취약점
스택 카나리(-fstack-protector-all)가 있어 단순 오버플로우는 `__stack_chk_fail` 로 막힌다.
그러나 1단계 상태조회에서 `read(0, buf, 64)` 로 버퍼를 채운 뒤 **경계 없는**
`write(1, buf, 80)` 로 반향하면 버퍼(64) 너머 카나리(rbp-8 = buf+72)까지 노출된다.
공격자는 유출한 카나리를 2단계 오버플로우에서 제자리에 넣어 검사를 통과시키고 복귀주소를
`spillway_override` 로 덮는다(카나리 우회 → ret2win). 카나리의 LSB 가 0x00 이라 리틀엔디언
8바이트 중 첫 바이트가 0 인 값이 카나리다.

## 탐지 (Blue)
- 반향/출력 길이가 **버퍼 크기보다 큰 고정 상수**(64 버퍼에 80 write)인지 점검 — 인접 스택
  유출의 전형.
- 응답에 사용자 입력을 넘어 첫 바이트가 0x00 인 8바이트(카나리 형태)가 섞여 나오는지 관측.

## 패치
반향 길이를 **실제 읽은 바이트 수**로 제한한다.

```c
ssize_t n = read(0, buf, sizeof buf);   // 64
write(1, buf, n);                        // 80 → n. 인접 카나리 미노출
```

카나리를 유출하지 못하면 2단계 오버플로우는 카나리 검사에서 중단되어 ret2win 이 불가능하다.
일반 원칙: **출력 길이를 상수로 두지 말고 실제 데이터 길이로 제한**하고, 카나리·PIE·RELRO 등
표준 완화를 함께 적용한다.
