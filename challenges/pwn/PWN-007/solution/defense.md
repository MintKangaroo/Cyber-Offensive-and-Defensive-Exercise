# PWN-007 방어 — 포맷 스트링 임의쓰기 → 전역 함수포인터 하이재킹 차단

## 취약점
로그 메시지를 `printf(buf)` 로 **사용자 입력을 포맷 문자열로** 그대로 넘긴다. 공격자는
`%p`(정보 노출)뿐 아니라 `%n`/`%hn`(임의 주소 쓰기)을 쓸 수 있다. 입력 버퍼는 스택 arg 6 에
위치하므로, 버퍼 안에 목표 주소(&g_log)를 두고 `%1$<N>c%8$hn` 로 출력 문자 수 N 을 그 주소에
기록한다. `g_log`(정상 처리기로 초기화)과 `admin_shell` 이 같은 `0x40xxxx` 영역이라 하위 2바이트만
덮으면 `g_log = admin_shell` 이 되고, '로그 처리'가 `g_log()` 를 호출하며 `/flag` 가 노출된다.

## 패치
- **사용자 입력을 포맷 문자열로 쓰지 말 것**: `printf("%s", buf);` (가장 중요).
- 컴파일 경고를 오류로: `-Wformat -Wformat-security -Werror=format-security`.
- 완화: `_FORTIFY_SOURCE`(→ `__printf_chk` 가 쓰기형 포맷의 `%n` 차단), RELRO/PIE,
  민감 함수 포인터는 읽기전용 테이블+인덱스로(쓰기 가능한 전역에 두지 않기).

## 탐지 관점(blue)
- 로그 입력에 `%n`·`%hn`·다수의 `%p`·큰 폭 지정(`%12345c`) 패턴 관측 시 경보.
- 패치(`printf("%s",…)`) 후에는 포맷 지정자가 그대로 출력되어 임의쓰기가 불가.
