# WEB-001 방어 노트 (Blue)

## 취약점
`/api/net/ping` 이 사용자 입력 `host` 를 셸 문자열(`ping -c 1 {host}`)로 그대로 실행해
명령 주입(ATT&CK **T1059**)이 가능하다. `127.0.0.1; cat /app/flag.txt` 로 임의 명령 실행.

## 패치 (PATCH_WEB_001=true)
- **셸을 쓰지 않는다**: `subprocess.run(["ping","-c","1",host], shell=False)` — 인자를 배열로 전달해
  메타문자 해석을 차단.
- **입력 검증**: `host` 를 `^[A-Za-z0-9.\-]+$` 화이트리스트로 제한, 위반 시 400.

## 탐지
- 진단 파라미터에 `;`, `|`, `$(`, 백틱, `&&` 등 셸 메타문자가 들어오면 알림.
- 웹 프로세스가 예기치 않은 자식 프로세스(sh/cat 등)를 생성하는지 EDR로 감시(EDR-001과 연계).
