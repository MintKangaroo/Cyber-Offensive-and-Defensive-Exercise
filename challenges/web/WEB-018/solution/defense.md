# WEB-018 방어 — NoSQL 인젝션(인증우회) 차단

## 취약점
로그인이 username/password 를 문자열뿐 아니라 '연산자 객체'로도 받아 문서 질의에 그대로
넣는다. `password={"$ne": ""}` 는 임의 비밀번호와 매칭돼 admin 인증을 우회한다.

## 패치 (`PATCH_WEB_018=true`)
- 자격증명 필드를 **문자열로만 강제**(딕셔너리/연산자 객체 거부).
- 질의 파라미터를 타입 검증·정규화하고, 사용자 입력을 질의 연산자로 해석하지 않기.

## 탐지 관점(blue)
- 로그인 바디의 username/password 가 객체(`$ne`,`$gt`,`$regex` 등)로 들어오는 요청 경보.
