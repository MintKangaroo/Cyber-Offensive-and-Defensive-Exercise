# WEB-009 — WAF 우회 + 블라인드 SQLi 방어 노트 (Blue)

## 왜 WAF 만으로는 부족한가
문자 블랙리스트 WAF(공백/따옴표/`=` 차단)는 우회로가 많다.
- 공백 → 인라인 주석 `/**/`, 개행, 괄호
- `=` → `>` `<` `LIKE` `IN` `BETWEEN`
- 따옴표 → 문자열 리터럴 없이 `unicode()/substr()` 같은 컬럼 함수로 값 비교

블랙리스트는 근본 원인(신뢰되지 않은 입력의 쿼리 문자열 결합)을 없애지 못한다.

## 근본 해결 (PATCH_WEB_009=true)
1. **파라미터 바인딩**: `WHERE id = ?` 로 값과 코드를 분리. 문자열 결합 금지.
2. **입력 검증**: `id` 는 정수만 허용(`int(id)` 실패 시 400). 인젝션 페이로드는 진입조차 못 함.
3. (심화) 최소권한 DB 계정·에러 억제·행동 기반 탐지(불리언 오라클 남용 레이트리밋).

## 확인
패치판에서 우회 페이로드
`1/**/AND/**/(SELECT/**/unicode(substr(token,1,1))/**/FROM/**/secrets)>0`
는 정수 검증에 걸려 400 으로 거부되고, 블라인드 불리언 오라클이 사라져 플래그 추출이 불가능하다.
