# WEB-021 방어 — 웹 캐시 포이즈닝 차단

## 취약점
공유 캐시가 응답을 '경로만' 키로 저장하는데, 응답 본문은 언키드(unkeyed) 헤더
X-Forwarded-Host 를 자산 로더 호스트로 반영한다. 공격자가 악성 X-Forwarded-Host 로 캐시를
채우면 헤더 없는 일반 사용자에게도 오염된 본문이 제공된다.

## 패치 (`PATCH_WEB_021=true`)
- 응답에 영향을 주는 헤더는 **캐시 키에 포함**(Vary) 하거나, 신뢰할 수 없는 헤더(X-Forwarded-Host)
  를 응답에 반영하지 않기.
- 자산 호스트는 서버 설정 상수로 고정. 캐시 키 정규화.

## 탐지 관점(blue)
- 동일 경로에 대해 X-Forwarded-Host 등 언키드 헤더가 서로 다른 값으로 오는 요청, 이후 HIT 응답에
  외부 호스트가 반영되는 패턴 경보.
