# WEB-022 방어 — CSV/수식 인젝션 차단

## 취약점
사용자 신고 라벨이 CSV 로 내보내진 뒤 스프레드시트에서 열릴 때 `=`,`+`,`-`,`@` 로 시작하면
수식으로 실행된다. 수식이 다른(숨은) 셀을 참조하거나 `=HYPERLINK/=WEBSERVICE` 로 데이터를
유출/명령을 트리거한다.

## 패치 (`PATCH_WEB_022=true`)
- 내보내기 시 위험 접두(`=`,`+`,`-`,`@`, 탭/CR 포함)를 만나면 앞에 작은따옴표(')를 붙여
  **텍스트로 강제**(또는 셀을 큰따옴표로 감싸고 접두 이스케이프).
- 수치 필드는 숫자 타입 검증. 뷰어측도 신뢰할 수 없는 CSV 의 수식 자동계산 비활성화.

## 탐지 관점(blue)
- 신고/업로드 필드가 `=`,`+`,`-`,`@` 로 시작하거나 스프레드시트 함수명을 포함하는 경우 경보.
