# WEB-024 방어 — 2차(second-order) SQL 인젝션 차단

## 취약점
가입 시 username 을 파라미터 바인딩으로 '안전하게' 저장하지만(1차엔 무해), 나중에 요금 리포트
생성이 그 저장값을 문자열 결합으로 SQL 에 다시 넣는다. 저장된 UNION 페이로드가 이때 실행돼
비밀 테이블의 flag 가 유출된다.

## 패치 (`PATCH_WEB_024=true`)
- 데이터를 사용하는 **모든** 지점에서 파라미터 바인딩(prepared statement) 사용 — 저장 시점만이
  아니라 재사용 시점도.
- 신뢰 경계를 데이터 원천이 아니라 '쿼리 구성 시점'에 둔다. 최소권한 DB 계정.

## 탐지 관점(blue)
- 저장 필드에 SQL 메타문자('UNION','--',따옴표)가 포함되고, 이후 리포트/조회에서 예상 밖 컬럼이
  반환되는 패턴 경보.
