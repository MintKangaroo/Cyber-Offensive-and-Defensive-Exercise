# WEB-015 방어 — JWT 알고리즘 혼동(RS256→HS256) 차단

## 취약점
검증이 `algorithms=["RS256","HS256"]` 로 두 알고리즘을 모두 허용하면서 검증 키로 RSA
**공개키**를 넘긴다. 공개키는 누구나 볼 수 있으므로(/api/auth/pubkey), 공격자가 공개키를
HMAC 비밀키로 사용해 HS256 토큰을 위조하면(role=admin) 검증을 통과한다.

## 패치 (`PATCH_WEB_015=true`)
- 검증 알고리즘을 **RS256 하나로 고정**: `jwt.decode(token, PUB, algorithms=["RS256"])`.
- 대칭/비대칭 키 검증 경로를 분리하고, 대칭 비밀키를 절대 공개하지 않기.

## 탐지 관점(blue)
- 발급은 RS256 인데 헤더 alg 가 HS256 인 토큰이 검증을 통과/시도하는 경우 경보.
