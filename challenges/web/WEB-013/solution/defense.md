# WEB-013 방어 — SSRF 차단

## 취약점
신호 피드 수집기가 사용자가 지정한 URL 을 서버가 그대로 fetch 한다. 목적지 검증이 없어
공격자가 `http://127.0.0.1:8113/internal/flag` 같은 내부 전용 엔드포인트를 서버가 대신
호출하게 만든다(SSRF) → 루프백 전용 응답(flag)이 유출된다.

## 근본 원인
서버측 요청의 목적지를 신뢰하지 않고 사용자 입력으로 결정. 내부망/메타데이터/루프백으로의
요청을 막지 않음.

## 패치 (`PATCH_WEB_013=true`)
- fetch 대상 호스트를 DNS 해석 후 **루프백/사설/링크로컬/예약 대역이면 거부**.
- 허용 목록(allowlist) 도메인만 fetch, 리다이렉트 비활성(follow_redirects=False) 유지.
- 내부 엔드포인트는 네트워크 정책으로도 분리(앱 계층 검사에만 의존하지 않기).

## 탐지 관점(blue)
- fetch 파라미터가 사설/루프백 IP·내부 호스트명을 가리키는 요청 경보.
