# WEB-016 방어 — 레이스 컨디션(TOCTOU) 차단

## 취약점
바우처 상환이 '잔량 확인 → (처리 지연) → 차감' 순서로 **비원자적**이다. 동시에 여러 요청을
보내면 모두 같은 잔량(1)을 보고 통과해 한도를 넘겨 상환된다(이중 청구).

## 패치 (`PATCH_WEB_016=true`)
- 확인과 차감을 **원자적**으로: 락(mutex) 또는 DB 의 조건부 업데이트
  `UPDATE ... SET balance=balance-1 WHERE account=? AND balance>0` (영향 행수로 성공 판정).
- 멱등키(Idempotency-Key)로 중복 요청 무효화, 서버측 레이트리밋.

## 탐지 관점(blue)
- 짧은 시간창에 동일 계정의 상환 요청이 다수 병렬로 도착하는 패턴 경보.
