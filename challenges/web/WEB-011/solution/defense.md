# WEB-011 방어 — 권한 상승(Mass Assignment) 차단

## 취약점
회원가입 API 가 클라이언트가 보낸 `is_admin` 필드를 그대로 계정 권한에 반영한다.
일반 가입 요청에 `{"is_admin": true}` 를 넣으면 관리자가 되어 관리자 전용
`GET /api/admin/flag` 를 열람할 수 있다(수직적 권한 상승).

## 근본 원인
서버가 **입력 필드를 신뢰(over-trust)** 했다. 권한/역할은 클라이언트가 아니라
서버가 정책으로 결정해야 한다(mass assignment / auto-binding 결함).

## 패치 (`PATCH_WEB_011=true`)
- 가입 시 `is_admin` 은 무시하고 항상 일반 사용자로 생성한다.
- 관리자 승격은 별도의 인가된 관리 경로(운영자 승인)로만 가능해야 한다.
- 일반화: 요청 바디를 도메인 객체에 통째로 바인딩하지 말고 **허용 필드만
  화이트리스트**로 취한다. 역할·소유자·잔액 같은 민감 속성은 서버가 강제.

## 탐지 관점(blue)
- access-log 에서 일반 가입 직후 관리자 전용 엔드포인트 200 응답이 이어지는 패턴.
- 가입 요청 바디에 권한/역할 필드가 포함된 경우 경보.
