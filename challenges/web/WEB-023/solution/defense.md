# WEB-023 방어 — JWT kid 경로 주입 차단

## 취약점
JWT 검증이 헤더 `kid` 로 키 파일을 `keys/<kid>` 에서 로드하는데 kid 를 정규화하지 않는다.
`kid="../../../../dev/null"` 로 경로를 탈출해 빈 키(내용 0바이트)를 로드시키면, 공격자가 빈 키로
HS256 토큰을 위조해 검증을 통과한다(role=admin).

## 패치 (`PATCH_WEB_023=true`)
- kid 를 **basename 으로 축약 + 허용목록(allowlist)** 으로만 매핑. 경로 결합 금지.
- 키 저장소를 키-값 맵으로(파일 경로 노출 X), 빈/약한 키 거부.

## 탐지 관점(blue)
- kid 에 `/`, `..`, 절대경로, 널문자 등이 포함된 토큰 검증 시도 경보.
