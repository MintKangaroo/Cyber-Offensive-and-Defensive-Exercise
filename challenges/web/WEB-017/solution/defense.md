# WEB-017 방어 — SSTI(서버측 템플릿 인젝션) 차단

## 취약점
안내방송 미리보기가 사용자 입력을 Jinja2 템플릿으로 그대로 렌더한다. `{{7*7}}` 이 49 로
계산되는 것에서 SSTI 를 확인하고, `cycler.__init__.__globals__.os.popen(...)` 로 임의 명령을
실행해 로컬 파일(flag)을 읽는다.

## 패치 (`PATCH_WEB_017=true`)
- 사용자 입력을 **템플릿으로 렌더하지 말고 데이터로만 치환**(고정 템플릿 + 변수 바인딩).
- 부득이 사용자 템플릿을 허용해야 하면 SandboxedEnvironment + 화이트리스트, 자동 이스케이프.

## 탐지 관점(blue)
- 미리보기 입력에 `{{`, `__`, `globals`, `popen`, `os.` 등 템플릿/객체그래프 토큰 포함 시 경보.
