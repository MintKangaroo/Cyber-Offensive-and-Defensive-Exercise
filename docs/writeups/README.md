## 승리 조건 (기본 점수 정책)
- **Red**: 챌린지 플래그 획득(챌린지별 red 점수) + 트윈 목표 달성. 플래그는 팀별 HMAC 동적이라 공유 불가.
- **Blue**: 탐지 규칙 정답(탐지 챌린지 blue 점수) + 침해 자산 패치·복구(+50). MTTD/MTTR가 짧을수록 유리.
