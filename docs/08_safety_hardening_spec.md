# 안전장치 스펙 — Claude Code 빌드 프롬프트

> 로드맵 ★★★/★★ 안전 항목. 훈련 플랫폼은 의도적으로 취약한 서비스를 돌리므로,
> 익스플로잇이 실환경으로 새거나 플랫폼 자체가 악용되지 않도록 하는 것이 최우선.

---

## 1. 네트워크 격리 강화 (★★★)

**원칙**: 취약한 트윈은 인터넷/실내부망과 완전히 분리. 필요한 통신만 명시적 허용.

- **트윈 네트워크 `internal: true`**: docker-compose에서 트윈 전용 네트워크를 internal로 설정해 외부 egress 차단.
- **관리 경로만 개방**: 트윈 → Event Collector(range_control 네트워크)만 허용. 트윈끼리, 트윈 → 외부는 차단.
- **훈련용 Agent egress allowlist**: Reverse Connection Simulator의 outbound는 훈련용 Controller 목적지로만. 임의 인터넷 아웃바운드 금지.
- **전용 훈련 VLAN/서브넷**: 물리/클라우드 배포 시 훈련 환경을 별도 VPC/서브넷에 격리, 실내부망과 라우팅 없음.
- **점검 체크리스트**: 배포 스크립트가 트윈 컨테이너에서 `curl https://외부` 가 실패하는지 자동 검증(격리 회귀 테스트).

---

## 2. 더미 데이터 무결성 (★★★)

**원칙**: 실제 자격증명·기밀이 훈련 환경에 절대 유입되지 않게.

- 모든 flag/자격증명/문서에 `dummy`/`training-only` 마커 명시(이미 코드에 반영됨).
- **유입 방지 린트**: CI에서 트윈 코드/데이터에 실제 시크릿 패턴(정규식: AWS 키, private key 헤더, 실제 도메인 등)이 없는지 스캔(gitleaks/trufflehog 유사).
- 트윈 응답에 실데이터가 섞일 여지 차단: 외부 데이터 소스 연결 금지, 시드 데이터만 사용.
- 문서/UI에 상시 배너: "TRAINING ENVIRONMENT — ALL DATA IS SIMULATED".

---

## 3. 리소스 가드레일 (★★)

**원칙**: 취약점 악용이 호스트 자원 고갈·탈출로 이어지지 않게.

- **컨테이너 리소스 제한**: 트윈별 `cpus`, `mem_limit` 설정(예: 0.5 CPU, 512MB). DoS성 공격이 호스트 전체를 죽이지 못하게.
- **커맨드 인젝션 트윈(PP-003) 강화 격리**:
  - `read_only: true` 파일시스템 + 필요한 tmpfs만
  - `cap_drop: [ALL]`, `security_opt: [no-new-privileges]`
  - non-root 유저로 실행
  - 인젝션이 실제로 되더라도 할 수 있는 게 극히 제한되도록
- **역직렬화 트윈(PP-004)**: 별도 저권한 컨테이너 + 네트워크 최소화. RCE 시연이 컨테이너 밖으로 못 나가게.
- **타임아웃/레이트리밋**: 모든 트윈 엔드포인트에 요청 타임아웃과 팀별 레이트리밋(무한루프성 공격 방지).

---

## 4. 킬스위치 (★★)

(백엔드 스펙 6절과 연동)
- 교관 `POST /instructor/killswitch` → 전 트윈 maintenance 모드(503), 시나리오 강제 종료.
- 물리적 비상정지 개념: 훈련이 통제 불능(의도치 않은 동작, 자원 폭주)일 때 즉시 차단.
- 자동 트리거(옵션): 특정 자산의 리소스 사용률이 임계 초과하면 자동 킬스위치 + 교관 알림.

---

## 5. 감사·로깅 (교차 참조)

- 교관 조작 audit log(백엔드 4절).
- 플랫폼 접근 로그: 누가 어떤 뷰/API에 접근했는지(치팅·오남용 추적).
- 훈련 환경 자체의 보안: 대시보드/API에 인증 필수, 관전자도 익명 접근 금지.

---

## 6. 배포 전 체크리스트 (자동화 권장)

```
[ ] 트윈 컨테이너에서 외부 인터넷 egress 실패 확인
[ ] 트윈 간 직접 통신 차단 확인(range_control 경유만)
[ ] 실제 시크릿 패턴 스캔 통과(더미만 존재)
[ ] 커맨드인젝션/역직렬화 트윈 read-only + cap_drop 적용 확인
[ ] 리소스 제한 설정 확인
[ ] 킬스위치 동작 테스트
[ ] 대시보드/API 인증 활성 확인
[ ] "TRAINING ONLY" 배너 노출 확인
```

---

## 7. Definition of Done

- 트윈에서 외부 인터넷 접근 시도 → 차단됨(회귀 테스트 green).
- PP-003 커맨드 인젝션 성공해도 read-only FS·cap_drop로 실질 피해 없음.
- 교관 킬스위치 → 전 트윈 즉시 503, 강제 종료 이벤트 발행.
- CI 시크릿 스캔이 실데이터 유입을 차단.
