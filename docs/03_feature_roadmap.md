# Cyber Range — 추가·개선 기능 추천 로드맵

> 요청하신 대로 "추가하면 좋은 기능 / 개선하면 좋은 기능"을 계속 쌓아가는 문서입니다.
> 우선순위: ★★★(강력추천, 훈련 완결성에 직접 기여) / ★★(가치 높음) / ★(여유될 때).

---

## A. 훈련 완결성 (Red↔Blue 루프를 닫는 것)

- **★★★ 탐지→점수 자동 연결**: SIEM 알림이 곧 Blue 점수가 되게(이미 SIEM 프롬프트 7절에 반영). "공격했다"만이 아니라 "탐지했다/막았다"가 점수화돼야 Blue 훈련이 성립.
- **★★★ 서비스 복구(Recovery) 판정**: 현재 asset_recovered 이벤트는 있는데 발생 트리거가 없음. Blue가 취약점 패치 + 서비스 정상화하면 `asset_recovered`(+50) 자동 발행되도록 헬스체크 기반 판정 추가.
- **★★★ 다단계 시나리오(Kill Chain)**: 단일 취약점이 아니라 "GS-002 로그인 → GS-003 IDOR → PP-001 측면이동 → PP-005 목표"처럼 순서가 있는 시나리오. Exploit Manager의 Scenario Registry로 정의하고, 순서대로 달성 시 보너스 점수.
- **★★ 시간 감쇠 점수**: 공격이 오래 탐지되지 않으면 Red 추가 점수(dwell time 반영), 빠르게 탐지하면 Blue 보너스. 실제 SOC의 MTTD/MTTR 개념을 훈련에 주입.
- **★★ Hint/패널티 시스템**: Blue가 힌트를 열면 소폭 감점, Red가 탐지당하면 은신 점수 하락.

## B. 현실성 (실제 환경에 가깝게)

- **★★★ 트윈 구조화 access 로그**: 트윈이 SIEM용 JSON 로그를 별도로 남기게(SIEM 프롬프트 5절). 앱 레이어 공격을 SIEM이 볼 수 있게 하는 핵심.
- **★★ Reverse Connection Simulator 계측**: 제안서 8장의 훈련용 Agent(heartbeat/beacon)를 실제로 구현하고, 주기적 outbound를 SIEM이 "C2 비콘 의심"으로 탐지하는 규칙 추가. 안전하게 C2 탐지 훈련 가능.
- **★★ 네트워크 노이즈 생성기**: 정상 트래픽/로그를 배경으로 흘려서 공격 신호를 노이즈 속에서 찾는 훈련(신호 대 잡음). 없으면 탐지가 너무 쉬움.
- **★ OT/SCADA 프로토콜 모사**: PLC를 Modbus/S7 흉내 REST가 아니라 실제 Modbus 시뮬레이터(pymodbus)로 올려 OT 탐지(Zeek의 modbus 로그) 훈련.

## C. 대시보드/UX

- **★★ 리플레이(After-Action Review)**: 훈련 종료 후 이벤트 타임라인을 배속 재생. 디브리핑용으로 매우 강력.
- **★★ Red/Blue 분리 뷰 + 관전자 뷰**: 팀별로 자기 정보만 보이는 뷰, 교관/관전자는 전체. 정보 비대칭이 훈련 몰입감을 높임.
- **★★ 자동 리포트(제안서 13장 Phase 6)**: 팀별 성과, 탐지율, MTTD/MTTR, ATT&CK 커버리지 히트맵을 PDF로 생성.
- **★ 사운드/알람**: critical 알림 시 오디오 큐(워룸 몰입감). 토글 가능하게.

## D. 플랫폼/운영

- **★★★ Instructor Console audit log**: 점수 조정·이벤트 주입 전량 기록(대시보드 프롬프트 4절). 대회 신뢰성의 핵심.
- **★★★ 패치 토글 무중단화**: 현재 PATCH_* 환경변수는 컨테이너 재기동 필요. Redis/설정API로 런타임 토글(교관이 시나리오 중 취약점 on/off).
- **★★ 멀티팀/멀티라운드**: team_id는 이미 있음. 라운드/세션 개념 추가해 리더보드 누적.
- **★★ 시나리오 as-code**: 시나리오를 YAML로 정의(자산/취약점/목표/점수/시간)하고 로드. 재현성·공유성 확보.
- **★ RBAC**: 교관/Red/Blue/관전자 역할별 권한 분리.

## E. 탐지 콘텐츠 (SIEM 규칙 확장)

- **★★★ 초기 룰셋**: 포트스캔, 브루트포스, SQLi/경로순회, 오픈릴레이, PLC 미인증 쓰기, C2 비콘 주기성, 차단 급증.
- **★★ Sigma 호환**: 규칙을 Sigma 표준으로 작성해 커뮤니티 룰 임포트 가능하게.
- **★★ ATT&CK 커버리지 뷰**: 어떤 전술/기술을 탐지 가능한지 매트릭스로 시각화(빈틈 파악).
- **★ 오탐(FP) 훈련**: 일부러 애매한 정상 트래픽을 넣어 Blue의 트리아지 능력 평가.

## F. 안전장치 (훈련 플랫폼이므로 필수)

- **★★★ 네트워크 격리 강화**: 트윈 네트워크 `internal: true`, 외부 egress 차단(훈련용 Agent만 허용 목적지로). 익스플로잇이 실환경으로 새지 않게.
- **★★★ 더미 데이터 무결성**: 모든 flag/자격증명이 더미임을 코드/문서/응답에 명시(이미 반영). 실데이터 유입 방지 체크.
- **★★ 리소스 가드레일**: 트윈별 CPU/메모리 제한, 커맨드 인젝션 트윈은 컨테이너 권한 최소화·읽기전용 파일시스템.
- **★★ 킬스위치**: 교관이 전체 훈련을 즉시 정지/롤백하는 버튼.
